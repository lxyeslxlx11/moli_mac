# Windows 11 安装许可预查

核对日期：2026-10-25。仅查阅微软公开原始资料；不操作 UI、ISO 或 VM，不接受条款、购买或登录。本记录供安装器实际许可页出现后确认，不证明用户已获得许可，也不替代安装器展示的完整文本。

## 原始入口与可确认事实

| 来源 | 本次观察 | 适用边界 |
| --- | --- | --- |
| [Microsoft License Terms 总入口](https://www.microsoft.com/en-us/useterms) | 页面区分制造商预装、面向最终用户的零售包装以及组织许可；当前预装栏目 Windows → 11 提供各语言条款。 | 不能从 ISO 文件名确定用户的授权渠道。组织许可应依其对应协议核查，不套用普通零售/OEM结论。 |
| [Windows 11 英文条款 PDF](https://www.microsoft.com/content/dam/microsoft/usetm/documents/windows/11/oem-%28pre-installed%29/UseTerms_OEM_Windows_11_English.pdf) | PDF 标注 April 2024；虽然 URL 含 OEM，正文引言及 §1(a) 同时讨论预装与从零售商取得的软件。 | 这是目前成功读取的官方参考文本；并未确认它与 26H2 简体中文安装器文本逐字一致。本次没有确认独立 Windows 11 Retail PDF，因此不提供猜测出来的零售直链。 |
| [Microsoft：在 Apple M1/M2/M3 Mac 使用 Windows 11](https://support.microsoft.com/en-us/windows/experience/platform-variants/options-for-using-windows-11-with-mac-computers-with-apple-m1-m2-and-m3-chips) | 页面针对 **Windows 11 Pro** 说明每个物理或虚拟实例需独立适用许可，Pro 密钥不区分 x64/Arm；另列特定 Parallels 版本的官方方案。 | 不能把 Pro 说明改写为用户已选择 Pro；也不能推导 UTM 获得同样官方背书。未列 UTM 本身不构成违法结论。 |

**条款内容简述（事实，限上述 April 2024 PDF）：** §2(a)、§2(b)、§2(d)(iv) 涉及单一实例及物理/虚拟设备；后者短摘录为 “a separate license for each instance”。§4(a)/(b) 区分预装和独立取得软件的转移条件；不能仅因旧 VM 能启动就认定其许可可移用。§5 将适用许可与授权激活方式分开，并指出激活成功本身不证明许可适用。这里仅报告文本，不判断用户具体权利或当地法律效力。

## 到达许可页后的最小确认内容

**待验证：** 安装界面实际列出的版别、当前选择是否已由用户决定、许可正文标题/语言/更新标识，以及与用户现有授权的对应关系。在这些信息出现前，文档只称“Windows 11 ARM64 26H2 安装准备”，不写“已安装/选择 Windows 11 Pro”。如果到达许可页前必须先选择 Home/Pro 等版别，而用户适用版别未知，应在该选择点返回具体选项，不能为了进入下一页随意决定。

父会话可在观察到实际页面后给出如下简短确认说明，并把方括号替换成真实 UI 结果：

> 当前安装器显示的是［实际版别或尚未显示］，已停在微软许可页，尚未点击接受。请确认你已有适用于这个 VM 和所选版别的 Windows 许可，并明确是否同意页面展示的条款；可先在 Microsoft License Terms 查看原文。无需提供产品密钥或账号密码。

这个确认只针对 Windows 许可接受，不扩展为购买、订阅、账号登录、联网、执行官方游戏或修改主机安全设置。用户接受前保留页面，不勾选同意或点击具有接受效果的按钮。用户的历史“始终允许”不是本次许可接受记录。

微软总入口、上述英文 PDF、Mac 支持页和 ARM64 下载页均成功读取。总入口的栏目锚点/语言链接点击通过网页工具返回内部 500；两个按命名推断的独立 Retail/简体中文 PDF 路径返回 404，未据此宣称存在对应文件，也未改走非官方来源。以上是检索限制，不是已接受条款或安装失败。

已完成：公开原始资料的来源、措辞范围和确认条件。未完成：实际安装器条款匹配、用户授权类型核实、许可接受、激活和 Windows 安装；这些状态以主任务的 UI 证据为准。本文件没有保存条款全文、凭据、密钥或签名下载查询串。
